# Medical Devices - Signal Processing

MATLAB, Arduino and Python code for the Medical Instrumentation and Devices + Brain Machine Interfaces (UC3M)

- Radiation Detector: pulse integration, histograms and energy calibration of a Na-22 spectrum. Needs radiation_alu.mat from the course in the same folder.
- EMG_signal_analysis: MATLAB-based EMG signal analysis exploring muscle activation, force–EMG relationships, muscle fatigue, and dominant vs. non-dominant hand performance through signal visualization and data analysis.
- - ECG_signal_analysis: Python-based ECG filtering (median, FIR high-pass and notch filters) to remove noise, baseline drift and 60 Hz interference from an MIT-BIH recording, plus heart rate estimation from R peak detection.
